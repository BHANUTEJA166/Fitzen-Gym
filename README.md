Fitzen Gym

Fitzen Gym is a React application with an Admin Panel that manages gym data using CRUD operations.
The project uses JSON Server as a mock backend.

Tech Stack

React JS

React Router

Axios

Bootstrap

JSON Server

Features

Admin Login

Add / Edit / Delete Classes

Add / Edit / Delete Trainers

Add / Edit / Delete Schedules

View and Manage Enquiries

Admin Login

How to Run the Project
1. Clone the repository
git clone https://github.com/BHANUTEJA166/Fitzen-Gym.git
cd Fitzen-Gym

2. Install dependencies
npm install

3. Start the application
npm run dev


This command runs:

React app on http://localhost:3000

JSON Server on http://localhost:5000

Production Build

To create a production build:

npm run build

Project Structure

src/Fitzen – Main website components

src/Fitzen/Admin – Admin dashboard and CRUD components

db.json – Mock database
